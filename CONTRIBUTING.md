# Contributing

Thanks for helping improve PokeRarity.

## Before opening an issue

Please include:

- PokeRarity version
- Windows version
- whether the card is English or Japanese
- the printed collector number
- what PokeRarity returned
- relevant console/log output when reporting a crash or failed update

Do not post personal information or API credentials in an issue.

## Development setup

1. Use Windows with Python 3.12.
2. Run `setup.bat`, or create a Python 3.12 virtual environment manually.
3. Install `requirements.txt`.
4. Run `run.bat` while developing so console diagnostics remain visible.

## Pull requests

Keep changes focused and describe what was changed and how it was tested. For matching or OCR changes, include a reproducible card example when possible.
